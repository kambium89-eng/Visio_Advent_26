# Visio_Advent_26
Interaktiver Digitaler Adventskalender für Visio Coaching

## Test mit drei Türchen

Für diesen Test gilt der 7. Dezember 2026. Die Startseite zeigt Türchen 7.

- [5. Dezember: Die zwei Wölfe](https://kambium89-eng.github.io/Visio_Advent_26/?tag=5)
- [6. Dezember: Samichlaus](https://kambium89-eng.github.io/Visio_Advent_26/?tag=6)
- [7. Dezember: Calvin und Hobbes](https://kambium89-eng.github.io/Visio_Advent_26/?tag=7)

Am Seitenende führen nummerierte Schaltflächen zu den vorbereiteten vergangenen Türchen. Zukünftige Türchen bleiben bis zu ihrem Datum geschlossen.

Das Testdatum steht in `script.js` unter `TEST_DATE`. Mit `null` wird das tatsächliche Datum in der Zeitzone Europe/Zurich verwendet.

Die Website ist statisch. Die Ordner `Images`, `content` und `vendor` müssen neben `index.html` liegen.
